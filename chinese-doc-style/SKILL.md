# 中文文档格式规范

统一中文及中英文混排文档的格式，使内容清楚、自然且易于维护。格式调整应服务于
阅读，不应改变原意，也不应为了套用规则而破坏技术内容。

## 工作流程

1. 判断用户需要直接修改、重新编写，还是仅检查并报告问题。
2. 识别并保护不应改写的内容，例如代码、命令、URL、路径和标识符。
3. 按本规范处理词汇、空格、标点、大小写和地区用词。
4. 通读修改结果，检查含义、Markdown 结构和技术内容是否保持不变。
5. 按用户要求交付结果；用户没有指定时，直接提供规范化后的文本。

## 输出方式

- 用户要求“修改”“整理”“规范化”或“润色格式”时，直接输出修改后的完整内容。
- 用户要求“检查”“审查”或“指出问题”时，先列出问题、建议和理由；必要时再附上
  修改后的完整内容。
- 用户要求编辑文件时，直接修改文件并保留原有标题层级、列表结构、表格和代码块。
- 只报告有实际价值的修改。不要逐条解释机械重复的空格修正，除非用户明确要求。
- 遇到不确定的品牌写法、术语或标识符时，保留原文并指出疑点，不要自行猜测。

## 保护技术内容

以下内容默认保持原样：

- 围栏代码块和行内代码中的文本
- Shell 命令、命令行参数和环境变量
- URL、电子邮件地址和 Markdown 链接目标
- 文件路径、文件名、Git 分支名和版本号
- API 名称、函数名、类名、变量名及其他代码标识符
- 用户明确要求保留的引用或原文

可以调整这些内容与中文正文之间的空格，但不要修改其内部字符。Markdown 链接的
可见文字属于正文，可以按需修改；链接目标必须保持不变。

## 词汇与专有名词

### 选择明确、简洁的表达

在中文和英文之间，选择读者最容易理解且最简洁的说法。已经广泛使用的英文专名或
缩写不必生硬翻译。

正确：

> NBA

不建议：

> 北美职业篮球联赛

### 使用官方大小写

品牌、产品、项目和技术名称使用其官方写法。无法确认时，不要仅凭常见拼写自行
改动。

正确：

> 使用 GitHub 登录。

错误：

> 使用 Github 登录。
>
> 使用 github 登录。

## 空格

### 中文与英文之间增加空格

中文和拉丁字母组成的英文单词、缩写或专有名词之间增加一个半角空格。

正确：

> 本站点使用 Jekyll 搭建，应用 HPSTR 主题。文章保存在 `_posts` 目录下。

错误：

> 本站点使用Jekyll搭建，应用HPSTR主题。文章保存在`_posts`目录下。

### 中文与数字之间增加空格

中文和阿拉伯数字之间增加一个半角空格。

正确：

> 今天买菜花了 5000 元。

错误：

> 今天买菜花了5000元。

### 数字与单位之间增加空格

数字与中文量词或使用拉丁字母表示的单位之间增加一个半角空格。

正确：

> 我家的带宽是 1 Gbps，硬盘容量是 10 TB。

错误：

> 我家的带宽是 1Gbps，硬盘容量是 10TB。

不要机械拆分日期、时间、版本号、小数、百分比、比例、端口号、文件名或代码中的
数字，例如 `2026-06-09`、`v2.1.0`、`3.14`、`50%`、`16:9` 和
`localhost:3000`。用户或项目已有单位约定时，优先保持其一致性。

### 避免多余空格

- 中文标点前后通常不加空格。
- 行首、行尾不保留无意义的空格。
- 不要在 Markdown 标记内部随意加空格。
- 不要为了中英文间距破坏行内代码、链接或强调语法。

## 标点符号

### 中文句子使用全角中文标点

中文句子以及以中文为主的中英文混排句子使用全角中文标点，包括：

```text
，。！？：；（）“”《》、「」
```

正确：

> 核磁共振成像（NMRI）是什么原理？JFGI！

错误：

> 核磁共振成像(NMRI)是什么原理?JFGI!

### 完整英文句子使用英文标点

嵌入中文段落的完整英文句子使用半角英文标点。包裹该句的中文引号仍使用全角形式。

正确：

> 乔布斯说过：“Stay hungry, stay foolish.”

错误：

> 乔布斯说过：“Stay hungry，stay foolish。”

### 标点与空格配合

- 中文标点与相邻文字之间不加空格。
- 英文句子内部按英文规则使用空格。
- 中文括号用于中文句子中的补充说明，即使括号内是英文缩写。
- 不要把代码或 URL 内部的半角标点替换为全角标点。

## 中文链接

中文正文中的 Markdown 链接与前后中文之间建议增加空格，使链接边界清晰。

建议：

> 访问网站的最新动态，请 [点击这里](#) 进行订阅。

不建议：

> 访问网站的最新动态，请[点击这里](#)进行订阅。

链接位于句首、句末、标题、表格或本来就有标点分隔时，不要强行增加多余空格。

## 简繁体与地区用词

- 默认使用简体中文，除非用户或现有文档明确采用繁体中文。
- 默认采用中国大陆常用词，例如“程序”“软件”“硬盘”。
- 不要在同一篇文档中无意混用简体字和繁体字。
- 专有名词、引用、书名和用户指定文本可以保留原写法。
- 转换地区词汇时先确认语义，不要只做逐字替换。

## 最终检查

交付前确认：

- 专有名词大小写一致且没有误改标识符。
- 中文、英文、数字和单位之间的空格一致。
- 中文句子使用中文标点，完整英文句子使用英文标点。
- 代码块、行内代码、URL、路径和 Markdown 目标保持不变。
- 简繁体和地区用词符合文档上下文。
- 修改没有改变事实、语气、标题结构或列表层级。

## 与其他编辑任务的边界

本 skill 负责格式、书写规范和有限的地区用词统一，不负责主动重写文章风格。若用户
还要求去除 AI 写作痕迹、改变语气或大幅改写内容，应结合相应的写作编辑 skill；
完成内容层面的修改后，再用本规范做最终排版检查。
