# 中国大陆 STEM 术语规范

规范正式 STEM 文档中的中文术语和译名。只处理需要交付或审校的中文部分，不擅自把原有英文正文翻译成中文，也不把参考词表宣称为唯一或官方标准。

## 调用边界

自动调用以任务正在撰写、翻译、修改或审校正式 STEM 文档，且需要中国大陆中文术语为前提，例如供发布、交付或评审的技术报告、指南、教材和讲义。在聊天中起草正式文档也适用，不要求先有文件。

- 日常聊天、科学概念问答、代码讨论、临时翻译、单个术语释义和非正式学习笔记不自动调用。出现 STEM 主题、英文术语、Markdown、表格或文件路径，本身不构成正式文档写作任务。
- 没有正式文档用途，或用户说明只需理解大意、不必严格规范时，按普通交流处理，不为此追问或加载词表。仅阅读、总结、提取或核查内容而不处理文档措辞时也不调用。
- 规范只用于当前交付的文档正文，不扩展到过程说明或后续闲聊。用户明确要求使用本 skill 时，按其指定范围处理；仅提及或讨论 skill 名称不等于要求应用规范。

## 工作流程

1. 先遵循用户明确要求和项目现有术语表；混合学科内容分别判断学科。
2. 通读文本，列出所有需要查证的英文术语或可疑译名，连同上下文一起判断；同时标记需要保护的内容。
3. 把待查词合并成一次词表检索（见“参考词表”），不要逐词查询，也不要整份读入词表。
4. 根据语义和学科选择术语，同一含义统一译名，不做脱离语境的全局替换。
5. 一次性写出最终文本；不要为检查术语重读全文或另外多改一遍。

## 术语来源优先级

按以下顺序解决词条缺失或冲突：

1. 用户指定用词和目标项目的术语表。
2. 任务明确要求遵循的现行国家标准、权威术语库或专业机构规范。
3. 中国大陆主流教材、学术出版物和官方技术文档。
4. 中国大陆专业社群中含义明确、使用稳定的通行译法。
5. 本 skill 附带的主题词表。

第 2～4 项指依据自身知识和用户提供的资料判断，不要为了确认它们而联网检索。

不要在没有依据时声称某个译名是“国家标准”或“唯一正确译法”。无法可靠判断时保留原词，给出候选译法和需要确认的语境。仅在用户要求核查外部来源时才联网查证。

## 根据语境选择

同一英文词或相近概念可能因学科不同而使用不同中文名称。例如：

- `vector` 在数学中通常为“向量”，在物理中通常为“矢量”。
- `argument` 在复数中为“辐角”，在程序调用中为“实参”。
- `process` 在输入—处理—输出模型中为“处理”，在操作系统中为“进程”。
- `normalisation` 在浮点数表示中为“规格化”，在数据库中为“规范化”。

先判断所指概念，再选择词条。不要因为英文拼写相同而强行统一中文译名。

## 保护内容

除非用户明确要求，否则不要修改以下内容内部的字符：

- 公式、变量、符号和单位符号
- 围栏代码块、行内代码、命令和代码标识符
- API、协议、品牌、产品、课程和考试名称
- URL、链接目标、文件路径和文件名
- 直接引文、书名及用户要求保留的原文

可以规范这些内容周围的中文表述。原文同时保留英文术语时，只规范其中文对应项，不要擅自改写英文检索键。

## 输出要求

- 写作、改写或翻译任务：直接交付术语已经统一的完整内容。
- 术语审校任务：按用户要求直接修改，或列出“原词—建议词—理由/语境”。
- 只有在译名存在歧义、争议或资料不足时，才额外说明判断依据。
- 默认使用简体中文和中国大陆用词；目标项目另有明确约定时遵循项目约定。
- 保持术语准确，不为了行文变化而给同一概念轮换近义词。

## 参考词表

词表以英文为检索键，以中国大陆中文名称为建议结果，覆盖 CAIE A Level 的常见概念。它们是用户维护的种子资料，不是完整词典，也不替代上下文判断。

- 数学、力学和统计：`references/mathematics.md`
- 物理：`references/physics.md`
- 计算机科学：`references/computer-science.md`
- 化学：`references/chemistry.md`

词表每行一个词条，用一次 `rg -i -n 'term1|term2|term3' <涉及的词表>` 批量检索全部待查词；只有需要理解相邻概念时，才用 `rg -n -C 3` 或按行范围读取局部。不要整份读取词表；跨学科文本只检索涉及的主题词表；没有命中的词按语境和自身知识判断。

若同时使用风格或格式类 skill，在同一次写出中依次应用：内容和语气、本 skill 的术语、中文排版，避免后续改写重新引入不一致术语。不要为每个 skill 单独改写一遍文件；仅当用户要求专项审阅时才另行检查。
